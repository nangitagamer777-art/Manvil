# CVE-2025-8045 Notes

Use-after-free in the KCPU queue dump path. Affects r53p0 through r54p1
of the Mali Valhall and 5th Gen GPU Architecture kernel drivers.

## Value for Manvil

### KCPU timer behavior

The disclosure provides timing constants that describe the KCPU timer:

#define BUCKET_NS (256ULL * 1000000ULL)   // 256 milliseconds
#define WAIT_NS   (3000ULL * 1000000ULL)  // 3 seconds

The firmware processes timer events in buckets of 256 ms. A FENCE_SIGNAL
that is scheduled by a blocked CQS_WAIT will not fire immediately but at
the next 256 ms boundary.

Implication for Manvil: synchronization timeouts must account for this.
A five second timeout is safe; a one hundred millisecond timeout is not
guaranteed to see any event.

### CQS_WAIT is blocking

A KCPU queue can be stalled indefinitely by a CQS_WAIT on a condition
that never becomes true. The firmware does not preempt the wait. The
queue remains in the ISSUED state until either the condition becomes
true or the queue is terminated by the process.

Implication for Manvil: any code path that enqueues CQS_WAIT must have
a strategy for reaching a terminal state. The options are to ensure the
target condition eventually becomes true, or to terminate the queue and
create a new one.

### KCPU queue states

The disclosure describes the state transitions observed by the dump
path:

  ISSUED    a command has been enqueued and handed to the firmware
  COMPLETE  the firmware has finished the command
  PENDING   the command is in progress, waiting on a dependency

These are the states that CS_CPU_QUEUE_DUMP observes. They are internal
to the kernel and are exposed only through the dump, not through a
direct query ioctl.

### CS_CPU_QUEUE_DUMP buffer size

#define DUMP_BUF_SIZE 0xF000   // 61440 bytes, 60 KiB

The dump ioctl takes a user buffer of this size. Manvil should allocate
at least this much if it ever calls CS_CPU_QUEUE_DUMP for diagnostic
purposes.

### Kernel physical address base

#define KERNEL_PA_BASE 0x80000000

This value matches earlier observations. On a 39-bit virtual address
system the kernel space begins at 0x80000000 (2 GiB physical offset).

## Value for Manvil

High for timing and state information. Confirms that CQS_WAIT can block
indefinitely and that the KCPU timer operates on 256 ms buckets. These
shape the design of the sync module.

## Non-reusable content

The exploit payload, race calibration, heap grooming, and target
specific kernel symbol offsets are not recorded.
